# Activity chart design notes

This chart refresh uses a compact, distance aligned view for the three streams already present in a run. The visual decisions are grounded in the interaction and presentation patterns described by the providers below; they are not attempts to reproduce any provider's interface.

| Product | Official guidance observed | Decision for Runwise |
| --- | --- | --- |
| [COROS Activities Page & Activity Summary](https://support.coros.com/hc/en-us/articles/15284799576980-Activities-Page-Activity-Summary) | Activity details include pace/speed, heart rate, and elevation graphs. The expanded graph supports multiple values under one touch or drag position; structured workouts expose work, rest, and recovery phases in lap details. | Keep one shared distance cursor, retain custom interval bands, and make the combined chart easy to scrub. |
| [Strava Run Activity Pages](https://support.strava.com/en-us/articles/15401883-run-activity-pages) | Run pages describe a smoothed pace/elevation profile, cursor inspection, and toggles for available parameters beneath the chart. Splits and laps can highlight the corresponding profile region. | Smooth the foreground pace/heart-rate paths for readability, keep the series toggles, and preserve visible gap and provider-segment cues. |
| [Strava Elevation](https://support.strava.com/en-us/articles/15401909-elevation) | The elevation profile shows where climbing and descending occur. Strava notes that elevation sources contain noise and that smoothing/outlier handling is part of its processing. | Use a quiet elevation area and line as context behind the performance streams; keep the imported elevation values and missing-value gaps intact. |
| [Garmin GPS Running & Multisport Watches brochure](https://www8.garmin.com/fitness/pdfs/running_brochure.pdf) | The activity examples present pace, elevation, and heart rate as readable metric views with distance/time context and compact labels. | Reduce oversized axis typography and visual chrome so the data remains the focus. |
| [Apple Support: Run with Apple Watch](https://support.apple.com/en-euro/guide/watch/apd73a43493f/26/watchos/26) | Workout views can include heart rate, average pace, elevation, splits, and segments, and runners can customize which views appear. | Keep the three metrics independently switchable, with units in the legend and precise values in the shared inspection tooltip. |

The chart uses distance on the horizontal axis because the run's pace is estimated over a distance window. A lower-intensity elevation layer establishes route shape without competing with the pace and heart-rate lines. All values remain sourced from the imported telemetry; the redesign does not add or interpolate missing samples across declared gaps.
