# Activity presentation

## One-time classification

The owner confirmed that the 21.10 km activity on October 19, 2025 was a race. The September 14, 2026 cleanup preserved existing race and long-run labels, classified other runs of at least 10 km as long runs, and classified the remaining records as easy runs, as requested. The resulting 157 records contain 1 race, 24 long runs, and 132 easy runs.

This is an organizational heuristic, not a claim about physiological intensity. Distance alone is not used to identify races. All original fields and classification changes were saved in an ignored local audit backup before updating; verification confirmed that only `run_type` changed. Later manual changes remain available through the run editor and bulk editor.

## Sharing images

The share dialog renders an image locally for preview and PNG download. Opening it does not create a public share token. Existing previously created links remain managed in Settings.

Single-run images use recorded distance, moving pace when available, date, and optional historical weather. Missing weather is shown as unavailable rather than fabricated. Week and month images summarize the selected local calendar period. Running days count distinct dates, while training-type counts count activities, so two runs on the same day contribute one running day and two activities.

## Shoe history

Shoe totals retain initial mileage. Monthly and training-type breakdowns use recorded activities assigned to the shoe; initial mileage has no known activity dates or types and is not distributed into those breakdowns.
